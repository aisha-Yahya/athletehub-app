# AthleteHub App

تطبيق AthleteHub هو منصة مراسلة متكاملة ومتقدمة مبنية باستخدام إطار عمل Flutter. يقدم التطبيق تجربة دردشة فورية تشمل المحادثات الفردية والجماعية مع دعم كامل للفعاليات ومشاركة الملفات بأنواعها المختلفة والاتصال بالخادم في الوقت الفعلي.

## التقنيات المستخدمة
- **Flutter**: لبناء واجهة المستخدم وتطوير التطبيق لمختلف المنصات.
- **Provider**: لإدارة حالة التطبيق (State Management).
- **Dio / Http**: للاتصال بالخادم ومعالجة طلبات الـ API.
- **WebSockets (dart_pusher_channels / web_socket_channel)**: لتوفير تحديثات البيانات الفورية (Real-time) مثل إرسال واستقبال الرسائل.
- **Geolocator**: للتعامل مع الموقع الجغرافي ومشاركته.
- **Audioplayers / Record**: لتسجيل وتشغيل المقاطع الصوتية في الدردشة.
- **Image Picker / File Picker**: لاختيار ومشاركة الصور والملفات المختلفة.

## المميزات الرئيسية
- محادثات فردية وجماعية (Private & Group Chat).
- مشاركة الملفات المتنوعة (صور، مقاطع صوتية، موقع جغرافي، جهات اتصال).
- إدارة الفعاليات والمناسبات داخل الدردشة.
- حالة الرسائل (مرسلة، تم التسليم، مقروءة).
- تحديثات فورية للرسائل والبيانات باستخدام WebSockets.
- تخزين البيانات محلياً وإدارة الجلسات باستخدام Shared Preferences.

## طريقة التثبيت والتشغيل
لتشغيل التطبيق على بيئتك المحلية، اتبع الخطوات التالية:

1. تأكد من تثبيت Flutter SDK.
2. قم باستنساخ المستودع (Clone repository).
3. في مسار المشروع، قم بجلب الحزم والتبعيات:
   ```bash
   flutter pub get
   ```
4. قم بتشغيل التطبيق على المحاكي أو جهاز حقيقي:
   ```bash
   flutter run
   ```
*(ملاحظة: تأكد من إعداد وتشغيل خادم الـ API الخاص بالتطبيق مع إعدادات WebSockets الصحيحة لتعمل جميع الميزات بكفاءة)*
